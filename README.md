# favorit-parts-search

SPA для поиска запчастей: React 19 + Vite + Redux Toolkit + Bootstrap.

Деплой: https://favorit-parts-spa.vercel.app/

## Локальный запуск

1. Клонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/Nadezhda-v/favorit-parts.git
   cd favorit-parts
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте `.env` из примера и укажите API-ключ:

   ```bash
   copy .env.example .env
   ```

   ```env
   VITE_API_KEY=ваш_ключ
   ```

4. Запустите dev-сервер:

   ```bash
   npm run dev
   ```
